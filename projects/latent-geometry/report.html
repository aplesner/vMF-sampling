2The prerequisite, scoped honestly

The brief estimated per-row (μᵢ, κᵢ) batched sampling at anywhere from 2 days to 3 weeks and named it the binding constraint. The scoping finding: the range collapses once you look at the algorithm. The Wood/Ulrich rejection sampler's Beta proposal concentration depends only on the dimension, not on κ — so proposals stay row-independent and only the transform and acceptance test become (B,)-tensor operations ("mask-and-refill"). The rotation is one Householder reflection per row, already O(B·p). Nothing at T1–T3 scale (≤ 50k rows, p ≤ 512, batches on commodity GPUs) requires kernel-level work, which is the only place the 3-week upper bound could have come from.

Real number: ~1–2 days for the general per-row (μᵢ, κᵢ) version with statistical validation; the T1-critical subset (per-row μᵢ with a scalar per-layer κ_inject = c·κ̂_ℓ) is hours. Measured actual: under 1 day, shipped and validated. Downstream planning (Projects 1, 4, 6) can treat Gap A from the experiment roadmap as closed.

What shipped, beyond the roadmap decomposition:

  • The envelope parameter in rationalized form b = d / (2κ + √(4κ² + d²)) — cancellation-free at both ends, so the κ → 0 uniform limit and κ → ∞ regime need no series-patch special cases (the scalar samplers carry one).
  • p = 2 (per-row von Mises) and p = 3 (closed-form inverse CDF, expm1/log1p-stable at κ → 0) paths, matching the scalar sampler's special cases.
  • Rows with μᵢ = e1 exactly get a zero Householder vector (no-op), so the north pole needs no branch.
  • Per-call torch.Generator; the global RNG is never touched, and sampler construction cannot reset global state (a program-wide invariant).

3Dependency: Project 6's vmf-measure

Resolved before T1 started. vmf-measure v0.1.0 landed at commit 2f146ef with the frozen API and schema the shared constraints require (owner: Andreas Plesner). Project 5 pins the schema, not the numbers, through a single adapter (src/vmf_measure_adapter.py) that sys.path-inserts Project 6's src/ and refuses a major-version change. The full pin record is in vmf_measure_interface.md.

Smoke verification (2026-08-10): refusal mode returns the frozen string "not resolvable at this n" with kappa = None; the surface reproduces the constraints-file canonical cell (rel_rmse_surface(0.85, 512, 256) = 0.0063, i.e. the measured 0.63% cell); the uniform-null κ̂ q95 at (p = 512, n = 10⁴) is 5.38 — the scale of the matched null every reported κ̂ will be quoted against; bessel_ratio_ap is finite at p = 2048, the top of the T2 grid, where stock SciPy cannot compute at all. Null calibration for Project 5 is thereby entirely Project-6-sourced; nothing local is or will be written.

4Experiment plan and pre-registered conditions

  • T1 — angular dose–response and amplification (~5 GPU-h, the core). ResNet-18 (+ normalized variant), CIFAR-10, 3 seeds. Inject at κ_inject = c·κ̂_ℓ, c ∈ {0.25, 0.5, 1, 2, 4, 10}; accuracy vs closed-form dose A_p(κ); downstream displacement gives the layer-to-layer amplification matrix. PGD/AutoAttack and CIFAR-10-C displacements at matched accuracy degradation become noise-equivalent doses on the same curve. On-curve (Tramèr's picture in geometric form) and off-curve (a directional signature) are both the result; whichever lands gets reported.
  • T2 — p-sweep (~4 GPU-h). Fixed backbone, fixed n, head width p ∈ {64,…,2048}; κ̂ with matched nulls in every cell against the closed-form RMSE surface. Hard-blocked on the §3 freeze.
  • T3 — detection, Tramèr-compliant or not at all (~9 GPU-h), reported as a negative. Encoders shared across all detectors; LID and feature squeezing alongside Mahalanobis and energy; CIFAR-10-C control at matched clean-accuracy degradation; AutoAttack + Square held out (split declared in this repo before any tuning); adaptive attack with EOT-20; post-adaptive AUROC is the headline.
  • T4 — robustness gate (~11 GPU-h), expected to fail. Fast-AT pair, each arm with its own 5-point LR sweep, full masking screen. MDE stated up front: ~2.5–4.7 points at 3 seeds vs a literature-typical claimed 1–3. Kill condition: gap below MDE at tuned LRs, or any masking diagnostic failing in ≥ 2/3 seeds → intervention arm cancelled permanently, shipped as a falsification paragraph.

Pre-registration: each run config lands in configs/ with its success criterion and a commit hash before the run. Compute follows the shared constraints — 2× RTX 3090 as two independent workers, node-local /scratch for hot data, net_scratch for canonical storage; escalation only if VRAM actually forces it, logged with the reason.

5Guardrails — retired claims that must not come back

Both numerically refuted; do not reintroduce. (1) "A converged CIFAR-100 class at n = 500 < p = 512 is unestimable" — measured relative RMSE is 0.63%; at high concentration the bias floor is ≈ 1/n and "n < p" carries no information. (2) The KappaFace audit target — at n ≈ 70, p = 512, κ/p ~ 1–3 the rel. RMSE is 1.9–2.9% with Spearman(true, κ̂) = 0.995, and κ̂ is z-scored across classes before use, so any common bias cancels by construction.

The constructive reframe this project does carry: κ̂ is well-conditioned exactly where the trace-ratio NC1 statistic is not (singular pseudo-inverse at n_class < p), and T2's p-sweep at fixed backbone and fixed n is the direct empirical test that κ/p, not p, governs estimability — validation-on-trained-networks of Project 6's theory, cross-cited.
