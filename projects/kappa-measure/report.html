2The tool

from vmf_measure import kappa_hat, rel_rmse_surface, null_quantile, min_resolvable_n

est = kappa_hat(r_bar=0.05, p=512, n=70)
est.status   # "not resolvable at this n"
est.kappa    # None — no number ships below the boundary
est.rel_rmse # 2.87 — predicted, so callers see how far below they are

min_resolvable_n(0.05, 512)          # ~1.3e4 samples needed for 1% rel-RMSE
null_quantile("kappa_hat", 512, 70, 0.95)  # matched uniform null

Refusal is the default and the refusal string is part of the frozen schema. Passing n=None opts out of the check explicitly; refuse=False returns the number with the predicted error attached. The rectangular rule (R̄ > 0.19 AND n/p ≥ 10) is retired everywhere in the program: it denies p=512, R̄=0.85, n/p=0.5, where the measured relative RMSE is 0.64% — one of the best-conditioned cells we have.

3Log-Bessel at p ≥ 8192

SciPy's special.ive underflows to exactly zero above order ≈511, which makes even the admissibility formula uncomputable in stock SciPy at p = 4096 (ive(2047, κ) is NaN for κ ≲ 2048). vmf_measure.log_iv is a NumPy translation of the CUSF piecewise algorithm already tested in this repo (src/torch_log_iv.py), checked here against a 50-digit mpmath reference:

4D1: closed-form surface vs Monte Carlo

rel-RMSE(κ̂) ≈ hypot( amp·(1−R²)/(2nR²), 1/(κ√(n·A_p′(κ))) ) amp = 1 + 2R²/(1−R²) − 2R²/(p−R²)

Each cell draws up to 2000 independent vMF datasets (Householder NumPy sampler, PCG64DXSM) and compares the empirical relative RMSE of the joint-MLE κ̂ against the surface evaluated at the population R̄ = A_p(κ). Where the surface misses, it misses safe. The sub-2× cells are all at κ/p ≤ 0.2, deep inside the refusal region: the κ̂ distribution saturates, so the surface overestimates the error (emp/pred down to 0.45). The refusal decision is unchanged there — both numbers are far above any target — but dependent projects should not read predicted rel-RMSE > 1 as a quantitative error estimate.

5Audit: comparisons at unequal n and low κ/p

The census framing is not run — the yield model in the brief gives 0–2 consequential findings, for three structural reasons: a common upward bias makes ordinal comparisons at matched n conservative; infeasibility lives at κ/p ≤ 0.2, where an upward bias makes "near-isotropic" conclusions conservative too; and the flagship target already ships a matched null. The surviving attack surface is a comparison at unequal n in the low-κ/p regime — rare vs frequent tokens, small vs large classes. Verdicts are pre-registered (SCHEMA.md, commit 2f146ef) and phrased “not resolvable as reported at the original n”, never “wrong”.

Correction to the brief. The quoted spurious ratio of 3.01 at κ/p = 0.05, n_A=70 vs n_B=700 does not reproduce: the measured value is 2.10, stable across p ∈ {64, 512, 2048} and across estimators (MLE and Banerjee agree to 3 s.f. in this regime). The artifact's magnitude is bounded by √(n_B/n_A) = √10 ≈ 3.16, approached only at the uniform null; 3.01 is reached near κ/p ≈ 0.017, not 0.05. The structural conclusion — this is the one surviving attack surface — stands.
The matched-n controls survive, as predicted. Identical true κ at equal n gives ratio 1.000; a true ratio of 2.0 in a resolvable cell reads 1.999; and the brief's own illustration — true ratio 2.0, both arms at n=100, low κ/p — reads 1.267, exactly the predicted 1.267: the bias shrinks gaps, it does not inflate them. Note the matched-n low-κ/p control is individually refused (each arm's absolute κ̂ is meaningless) while its ratio is exactly 1 — refusal guards absolute claims; ordinal claims at matched n were never at risk.

6Nulls

Three matched nulls, definitions frozen in SCHEMA.md: uniform (closed-form: R̄² ~ χ²_p/(np), exact E[R̄²]=1/n), mean_removed (sample-mean direction projected out, renormalized), and covariance_matched (Gaussian with the data's empirical covariance, normalized to the sphere). Full grid in results/null_quantiles.csv (688 rows).

The mean-removed null is near-degenerate — a finding, not a bug. Projecting out the sample-mean direction makes the un-normalized resultant vanish exactly (Σy_i = 0 by construction), so the renormalized R̄ null is second-order: q95 = 0.0008 against 0.1256 for the uniform null at p=512, n=70 — a 163× gap. Any pipeline that mean-centers before normalizing lives on this null, and judging it against √(1/n) would manufacture concentration out of thin air.

Pending (D3): Ethayarajh anisotropy, IsoScore, effective rank, participation ratio on the same grid. For isotropic data, PR = p/(1 + p/n) reproduces simulation to three decimals — textbook Marchenko–Pastur, budgeted ~5 core-hours to confirm and cite, not a contribution.

8Scope & caveats

  • CPU-only, float64, single machine (Apple M3 Max) for every number on this page. Monte Carlo cells use one seed each with 60–2000 replicates; precision comes from replication against a deterministic formula, not from seed sweeps.
  • The census was not run, deliberately. The yield model retains 0–2 consequential findings from 60–120 harvested claims; section 5 covers the one attack surface that survives the three structural filters.
  • Refusal ≠ ordinal safety. vmf-measure refuses per-arm, on absolute error. An ordinal comparison at matched n can be valid where both arms refuse; the tool does not adjudicate ordinal claims.
  • Audit verdicts are simulation-based. The 12–20-claim reproduction subset on original checkpoints is pending; substituting checkpoints would make it a different experiment.
  • D5 is pending. The SciPy ive underflow (exact 0 above order ≈511; NaN for ive(2047, κ), κ ≲ 2048) still needs its upstream report and the log-Bessel contribution.
  • Numbers may move. Dependents pin the schema, not the values; null quantiles will tighten as MC reps grow.
